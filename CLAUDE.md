## Product

- **Type:** web
- **Who uses it / why:** Demo marketing site used to exercise the software factory pipeline. Currently still the
  unmodified create-next-app starter page.
- **Production:** Not recorded. Deploy provider is Vercel (`main` is the production branch); no URL is known yet.

## Stack

- Next.js 16.4 (App Router, Turbopack), React 19, TypeScript (strict), npm.
- Styling: plain CSS (`globals.css`, CSS modules such as `page.module.css`). No Tailwind.
- Fonts: Geist and Geist Mono via `next/font/google`.
- Lint: ESLint 9 with `eslint-config-next`. No test runner, no e2e, no data layer or auth.
- Hosting: Vercel.

## Architecture map

- `src/app/`: App Router. `layout.tsx` (root layout, fonts, metadata), `page.tsx` (home), `globals.css`, `page.module.css`.
- `public/`: static assets (starter SVGs).
- `docs/specs/`: specs written by `/factory:spec`.
- `next.config.ts`: enables `cacheComponents` and `partialPrefetching`.
- `AGENTS.md`: Next.js agent rules; it points to the bundled docs in `node_modules/next/dist/docs/`.

None beyond the factory standards. The site has no tests yet, so verification is lint, typecheck and build.

## Gotchas

- This Next.js version differs from older releases. Read `node_modules/next/dist/docs/` before using its APIs (see `AGENTS.md`).
- `cacheComponents` is on, so dynamic data access needs to follow Cache Components rules (Suspense or `use cache`).
- `LayoutProps` / `PageProps` are globals generated by Next into `.next/types`. On a fresh checkout
  `tsc --noEmit` fails with "Cannot find name 'LayoutProps'" until `next typegen` (or a build) has run,
  which is why the `typecheck` command runs `next typegen` first.
- Layout metadata is still the create-next-app default ("Create Next App"). Fix before launch (SEO standards).
